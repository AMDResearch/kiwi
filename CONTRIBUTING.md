# Contributing to KIWI

Bug reports, questions, and pull requests are welcome through GitHub issues
and pull requests on this repository.

- Open pull requests against `main`. Keep each one focused, and describe how
  you tested it (GPU, ROCm version, commands run).
- New source files start with the AMD copyright line and
  `SPDX-License-Identifier: MIT`. Code adapted from another project keeps its
  original copyright and license and is listed in `NOTICES.txt`.
- Maintainers validate changes on AMD GPU hardware before merging, so review
  can take a little longer than the hosted CI checks.

KIWI is developed primarily in a maintainer repository and published here in
periodic batches. Batched updates appear on `main` as single commits; merged
pull requests keep their authorship.

By contributing, you agree that your contributions are licensed under the
MIT License in `LICENSE`.
